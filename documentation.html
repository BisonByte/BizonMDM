BizonMDM

Mobile Device Management Platform

Instalación en Windows

  1. Descarga e instala Python 3 y Git.
  2. Clona el repositorio: git clone https://github.com/BizonTeam/BizonMDM.git
  3. Instala las dependencias del servidor: pip install -r server/Servidor/requirements.txt
  4. Ejecuta el script de instalación: python server/install_script.py
  5. Completa el formulario de instalación en http://localhost:5000/install.

Instalación en un servidor privado (VPS)

  1. Prepara un servidor con Linux, Python 3 y Git instalados.
  2. Clona el repositorio y entra al directorio.
  3. Instala las dependencias con pip y configura variables de entorno necesarias.
  4. Ejecuta python server/install_script.py y sigue las instrucciones.
  5. Inicia el servidor con python server/Servidor/server.py o configura systemd para levantarlo automáticamente.

Preguntas frecuentes

¿Puedo usar otra base de datos? Sí, siempre que SQLAlchemy la soporte. Actualiza la cadena de conexión en el instalador.

¿Puedo escalar la aplicación? Se recomienda usar contenedores y balanceadores de carga para despliegues grandes.

Paso a paso para usar la aplicación

  1. Compila e instala la aplicación móvil en los dispositivos Android.
  2. Registra cada dispositivo mediante el código QR generado en el panel.
  3. Desde el panel de administración envía acciones como bloqueo o borrado.

Paso a paso para configurar la aplicación con el servidor

  1. Durante la instalación del servidor, ingresa la URL pública que usarán los dispositivos.
  2. En la aplicación móvil, edita el archivo de configuración para apuntar a dicha URL.
  3. Verifica la conexión realizando un inicio de sesión desde el dispositivo.

Paso a paso para integrar Firebase

  1. Crea un proyecto en Firebase Console.
  2. Genera una clave de servidor para Firebase Cloud Messaging.
  3. Introduce la clave en el instalador del servidor o en el archivo fcm_key.txt.
  4. Agrega el archivo google-services.json a la carpeta mobile/app/ del proyecto Android.
  5. Compila de nuevo la aplicación móvil para habilitar las notificaciones push.

Install on Windows

  3. Install server dependencies: pip install -r server/Servidor/requirements.txt

Install on a private server (VPS)

  1. Prepare a Linux server with Python 3 and Git installed.
  2. Clone the repository and enter the directory.
  3. Install dependencies with pip and configure required environment variables.
  4. Run python server/install_script.py and follow the prompts.
  5. Start the server with python server/Servidor/server.py or use systemd for automatic startup.

Frequently Asked Questions

Can I use a different database? Yes, as long as it is supported by SQLAlchemy. Update the connection string in the installer.

Can the application scale? For large deployments, consider containers and load balancers.

Step-by-step usage

  1. Build and install the mobile app on Android devices.
  2. Register each device using the QR code generated by the admin panel.
  3. Send actions such as lock or wipe from the admin panel.

Step-by-step server configuration

  1. During server setup provide the public URL that devices will use.
  2. In the mobile app edit the configuration file to point to that URL.
  3. Verify connectivity by logging in from the device.

Step-by-step Firebase integration

  1. Create a project in Firebase Console.
  2. Generate a server key for Firebase Cloud Messaging.
  3. Enter the key in the server installer or the fcm_key.txt file.
  4. Add the google-services.json file to the mobile/app/ folder of the Android project.
  5. Rebuild the mobile app to enable push notifications.
