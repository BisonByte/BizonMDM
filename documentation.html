BizonMDM es una plataforma de Mobile Device Management (MDM) de código abierto diseñada para la gestión de dispositivos Android. About BizonMDM

BizonMDM is an open-source Mobile Device Management (MDM) platform designed for Android device management. It allows administrators to register devices, apply security policies, send remote commands, and monitor activity through a centralized administration interface.

Server Installation

Prerequisites

Before you begin, make sure you have the following components installed on your server:

  • Python 3.8 or higher.
  • Git to clone the repository.
  • pip to manage Python dependencies.

Step-by-Step Installation on a Private Server (VPS)

This detailed guide will walk you through the necessary steps to set up and run the BizonMDM server in a Linux environment, such as a VPS.

  1. Clone the Repository

    Use Git to clone the BizonMDM repository to your server and navigate to the project directory.

    git clone https://github.com/BizonTeam/BizonMDM.git
cd BizonMDM

  2. Virtual Environment Setup (Optional but recommended)

    To isolate project dependencies and avoid conflicts with other packages on your system, you can create and activate a virtual environment.

    python3 -m venv venv
source venv/bin/activate

  3. Install Dependencies

    Install all necessary Python libraries for the server using the requirements.txt file.

    pip install -r server/Servidor/requirements.txt

  4. Run the Installation Script

    This script simplifies the initial configuration. It will prompt you for important data to set up the database and system security.

    python server/install_script.py

    This command will start a temporary server and ask you to fill out a form in your browser at http://localhost:5000/install. This form will automatically configure environment variables and the database.

  5. Server Configuration and Startup

    After the initial installation, you can start the main server.

    python server/Servidor/server.py

    The server will run on http://0.0.0.0:5000/ by default. You can change the host and port using the environment variables BIZON_HOST and BIZON_PORT.

  6. Optional JWT and HTTPS Configuration

    For enhanced security, you can configure a secret key for JWT and enable HTTPS.

    • JWT: Define the JWT_SECRET environment variable to protect all endpoints with a valid JWT token.
    • HTTPS: To enable HTTPS, set the SSL_CERT and SSL_KEY variables with the paths to your certificate and private key, respectively.

Provisioning QR Code Generation

BizonMDM supports provisioning Android devices via a QR code. This allows for quick, hands-free setup.

  1. Prepare the APK

    Ensure that the mdm.apk file is available in the downloads/ directory on your server.

  2. Generate the QR

    Access the following URL in your browser to generate a unique QR code for each device:

    http://<host>:<port>/provisioning/qr/<deviceId>

    Scan this code with the setup wizard of a newly factory-reset Android device, and the system will automatically download and activate the app.
